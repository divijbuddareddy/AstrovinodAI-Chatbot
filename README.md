

## Data sources

- Indian place names and coordinates: [GeoNames](https://www.geonames.org), licensed [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Rebuild `app/places_india.tsv.gz` with `tools/build_places.py`.
- Planet positions: NASA JPL DE421 ephemeris (public domain) via Skyfield.
